# Журнал тренировок

Свой план тренировок с автоподстройкой весов, дневник, награды и выгрузка в Excel. Аккаунты без почты: логин выдаём сами, вход по 6-значному коду. Правила разработки — [CLAUDE.md](CLAUDE.md).

Одна репа, независимые проекты (у каждого свои `package.json` и `node_modules`):

- `apps/backend/`: NestJS 11, TypeORM + Postgres, Swagger.
- `apps/web/`: React + Vite, FSD, Tailwind, TanStack Query, React Router. Дизайн-система «Flying Papers» (как в FAS). Клиент и кабинет тренера.
- `apps/admin/`: админка на том же стеке: тренеры, клиенты, промпты ИИ, статистика.

## Запуск

Весь стек в Docker одной командой:

```bash
docker compose -f docker-compose.dev.yml up --build
```

| Сервис | Адрес |
|---|---|
| Приложение | http://localhost:5190 |
| Админка | http://localhost:5191 (dev: `admin` / `dev-admin-password`) |
| API / Swagger | http://localhost:3020/api, http://localhost:3020/docs |
| Postgres | `localhost:5462`, БД/пользователь/пароль `gym` |

Порты нестандартные, чтобы не пересекаться с другими проектами. Dev-секреты прописаны в compose, код монтируется в контейнеры; после изменения `package.json` нужен `up --build`.

Без Docker для приложений (только Postgres в Docker):

```bash
docker compose -f docker-compose.dev.yml up -d postgres
cp apps/backend/.env.example apps/backend/.env.development
npm --prefix apps/backend install && npm --prefix apps/backend run start:dev
npm --prefix apps/web install && npm --prefix apps/web run dev
npm --prefix apps/admin install && npm --prefix apps/admin run dev
```

## Что умеет

- **Аккаунт.** «Создать аккаунт» → сервер выдаёт логин вида `otter-4821` и код из 8 цифр; они показываются один раз. Дальше вход — только кодом, без логина: экран как разблокировка iPhone (точки, круглая клавиатура, тряска при ошибке). Устройство, где уже входили, сразу открывает экран кода. Код хранится хешем (scrypt + соль + секрет `CODE_PEPPER`) и HMAC-ключом для поиска; подбор режется лимитом по IP (5 попыток в минуту, 100 в день). Старые аккаунты с 6-значным кодом входят как раньше — логином и кодом, как паролем («Войти по логину»); сменив код в «Плане», они получают 8 цифр и дальше входят одним кодом.
- **Программа пользователя.** При регистрации — готовая программа «для спины» из «План тренировок.xlsx» или пустая. Упражнения можно добавлять и менять: мышцы, повторы/секунды/минуты, нагрузка от рабочего веса (55→85% по неделям) или свой план на 4 недели, шаг веса, дни недели, замена-альтернатива, нюансы. Расписание (дни зала, по желанию, отдых) и правила безопасности тоже свои.
- **Сегодня** — упражнения дня по расписанию, аккордеоны с нюансами и историей, черновики правок с «Вернуть по умолчанию» (хранятся на сервере), сложность и боль 0–10, автоподстройка: боль 4+ → вес на 15% ниже, сложность 8+ → повтор нагрузки, до 4 → больше повторов; после 4-й недели — новые базовые веса. Подходы отмечаются кружками (тап по отмеченному — поправить повторы), после подхода и «Сделано» идёт таймер отдыха над меню (60/90/120/180 с, «+15 с», в конце вибрация и сигнал). Тап по числу в степпере — точный ввод с клавиатуры.
- **Без интернета.** Программа, дневник и черновики сохраняются на телефоне (до 7 дней), приложение открывается и без сети. «Сделано» без сети ложится в очередь на телефоне (отдельно для каждого аккаунта) и уходит само, когда сеть появится; такие записи видны в дневнике с пометкой и правятся прямо в очереди.
- **План** — неделя цикла и свои упражнения с весами этой недели (только просмотр). «Изменить» открывает правку: последний вес, подходы, дни, нюансы, порядок, новые упражнения. Отдельные страницы: «Дни тренировок», «Неделя и сброс» (повтор недели, переход на неделю со сбросом подстройки, полный сброс), «Правила безопасности».
- **Профиль** — аккаунт (смена кода, выход), итоги и разделы:
  - **Дневник** — записи по дням (тап — исправить вес, подходы, сложность, боль, заметку), выгрузка `.xlsx` («Дневник», «Веса на 4 недели», «Сводка»), загрузка `.xlsx` с прошлыми тренировками;
  - **Награды** — сколько поднято сегодня и всего, сравнения («как поднять 1 гориллу», «перетаскать 3 легковушки»), коллекция от кошки до Эйфелевой башни, значки, личные рекорды.

## Тренеры, ИИ и админка

- **Админ** входит в `apps/admin` логином и паролем. Первый админ создаётся при старте бэкенда из `ADMIN_LOGIN` / `ADMIN_PASSWORD` (в dev — `admin` / `dev-admin-password`). Админ заводит тренеров (код входа показывается один раз), выдаёт новый код, блокирует, задаёт дневной лимит ИИ, назначает клиентам тренеров, правит промпты ИИ и смотрит статистику и ошибки анализов.
- **Тренер** входит своим кодом в то же web-приложение и попадает в кабинет `/coach`: список клиентов с сигналами («боль 4+ за 2 недели», «7+ дней без тренировок»), «Новый клиент» (аккаунт с программой, код входа — тренеру) и «Пригласить» (одноразовый код на 7 дней для клиента, у которого уже есть аккаунт). На странице клиента:
  - карточка «Здоровье и цели»: болезни, травмы, ограничения, цели текстом;
  - ИИ-анализ: дневник за 12 недель → программа → отчёт и правки весов и схемы галочками, числа можно поправить, «Применить»;
  - графики прогресса;
  - история правок;
  - «План» и «Дневник» клиента: план с правкой, дневник только для чтения.
- **Клиент** видит правки тренера на «Сегодня» («Тренер изменил программу», с причиной), в «Профиле» → «Мой тренер» вводит код приглашения или отвязывается.
- **ИИ** — агент на платформе ultra-ai. Как его настроить и что он получает и отвечает — [docs/ai-agent-contract.md](docs/ai-agent-contract.md). Дизайн — [docs/superpowers/specs/2026-10-17-coach-admin-ai-design.md](docs/superpowers/specs/2026-10-17-coach-admin-ai-design.md).

### Импорт Excel

Файл разбирается в браузере, сначала показываем превью. Колонки ищутся по заголовку: «Дата», «Неделя», «Упражнение», «Вес», «Подходы», «Повторы», «Боль в спине», «Сложность (0–10)», в старых выгрузках «Как пошло» (Легко/Норм/Тяжело = 3/5/9), «Заметки». Подходят наша выгрузка и лист «Дневник» из «План тренировок.xlsx» (его первая строка — пример, она пропускается). Упражнения сопоставляются с программой по полному или короткому названию без учёта регистра. Ненайденные можно сразу добавить в программу (галочки в превью): мышцы угадываются по названию, рабочий вес — лучший из файла, без веса — подходы и повторы последней записи; записи к ним привязываются. Повторная загрузка того же файла дублей не создаёт.

### Перенос из прежней версии

Старая версия хранила всё в `localStorage` (`training-journal:v1`, `training-settings:v1`, `training-drafts:v1`). Если новое приложение открыто на том же адресе, после входа на «Сегодня» появится карточка «Нашли старые тренировки»: переносятся записи («как пошло» → сложность), дата старта, замены, рабочие веса и сегодняшние черновики. Старые ключи не удаляются. На другом адресе этих данных не видно — тогда выгрузить Excel в старой версии и загрузить его здесь.

## Приложение на телефоне (PWA)

Веб-приложение ставится на экран «Домой» и открывается на весь экран, без панелей браузера.

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран „Домой“». Подсказка есть на «Сегодня» (её можно скрыть) и в «Плане».
- **Android / Chrome:** кнопка «Установить» на тех же карточках или «Установить приложение» в меню браузера.

Манифест — `apps/web/public/manifest.webmanifest`, service worker — `apps/web/public/sw.js`. Он кэширует оболочку и статику, чтобы приложение мгновенно открывалось и без сети, а `/api` всегда ходит в сеть. Регистрируется только в production-сборке. Иконки рисуются из `apps/web/icons/*.svg` скриптом `sh apps/web/icons/render.sh` (нужны Chrome и Pillow). Для установки нужен HTTPS (на Railway он есть) или localhost.
