# Журнал тренировок

Простое приложение без аккаунтов для записи тренировок по 4-недельному плану, с выгрузкой в Excel.

- **Сегодня** — упражнения дня с предложенными весами; по тапу аккордеон с нюансами техники, историей и записью (вес, подходы, повторы, «как пошло», боль в спине 0–10).
- **Автоподстройка** — боль 4+ → вес на 15% ниже, «тяжело» → повтор нагрузки, «легко» → больше повторов; после 4-й недели предлагает новые базовые веса.
- **Дневник** — все записи и выгрузка в `.xlsx` (листы «Дневник», «Веса на 4 недели», «Сводка») в стиле «Flying Papers».
- **План** — веса по неделям (пересчёт от «последнего веса», округление до 2,5 кг), расписание, правила, повтор недели, переход на неделю со сбросом, полный сброс.

Данные хранятся в `localStorage` браузера.

```bash
npm install
npm run dev
```

Программа (упражнения, проценты, правила) — `src/lib/program.ts`, логика подстройки — `src/lib/suggest.ts`.
