# Журнал тренировок

Свой план тренировок с автоподстройкой весов, дневник, награды и выгрузка в Excel. Аккаунты без почты: логин выдаём сами, вход по 6-значному коду. Правила разработки — [CLAUDE.md](CLAUDE.md).

Одна репа, независимые проекты (у каждого свои `package.json` и `node_modules`):

- `apps/backend/`: NestJS 11, TypeORM + Postgres, Swagger.
- `apps/web/`: React + Vite, FSD, Tailwind, TanStack Query, React Router. Дизайн-система «Flying Papers» (как в FAS).

## Запуск

Весь стек в Docker одной командой:

```bash
docker compose -f docker-compose.dev.yml up --build
```

| Сервис | Адрес |
|---|---|
| Приложение | http://localhost:5190 |
| API / Swagger | http://localhost:3020/api, http://localhost:3020/docs |
| Postgres | `localhost:5462`, БД/пользователь/пароль `gym` |

Порты нестандартные, чтобы не пересекаться с другими проектами. Dev-секреты прописаны в compose, код монтируется в контейнеры; после изменения `package.json` нужен `up --build`.

Без Docker для приложений (только Postgres в Docker):

```bash
docker compose -f docker-compose.dev.yml up -d postgres
cp apps/backend/.env.example apps/backend/.env.development
npm --prefix apps/backend install && npm --prefix apps/backend run start:dev
npm --prefix apps/web install && npm --prefix apps/web run dev
```

## Что умеет

- **Аккаунт.** «Создать аккаунт» → сервер выдаёт логин вида `otter-4821` и код из 6 цифр, они показываются один раз. Вход — экран как разблокировка iPhone: точки, круглая клавиатура, тряска при ошибке. Логин запоминается на устройстве, дальше нужен только код. Код хранится хешем (scrypt + соль + секрет сервера `CODE_PEPPER`); после 5 неверных кодов подряд аккаунт блокируется на 15 минут, плюс лимит запросов по IP.
- **Программа пользователя.** При регистрации — готовая программа «для спины» из «План тренировок.xlsx» или пустая. Упражнения можно добавлять и менять: мышцы, повторы/секунды/минуты, нагрузка от рабочего веса (55→85% по неделям) или свой план на 4 недели, шаг веса, дни недели, замена-альтернатива, нюансы. Расписание (дни зала, по желанию, отдых) и правила безопасности тоже свои.
- **Сегодня** — упражнения дня по расписанию, аккордеоны с нюансами и историей, черновики правок с «Вернуть по умолчанию» (хранятся на сервере), сложность и боль 0–10, автоподстройка: боль 4+ → вес на 15% ниже, сложность 8+ → повтор нагрузки, до 4 → больше повторов; после 4-й недели — новые базовые веса.
- **Дневник** — записи по дням, выгрузка `.xlsx` («Дневник», «Веса на 4 недели», «Сводка»), загрузка `.xlsx` с прошлыми тренировками.
- **Награды** — сколько поднято сегодня и всего, сравнения («как поднять 1 гориллу», «перетаскать 3 легковушки»), коллекция от кошки до Эйфелевой башни, значки, личные рекорды.
- **План** — неделя цикла, повтор недели, переход на неделю со сбросом подстройки, полный сброс, выход.

### Импорт Excel

Файл разбирается в браузере, сначала показываем превью. Колонки ищутся по заголовку: «Дата», «Неделя», «Упражнение», «Вес», «Подходы», «Повторы», «Боль в спине», «Сложность (0–10)», в старых выгрузках «Как пошло» (Легко/Норм/Тяжело = 3/5/9), «Заметки». Подходят наша выгрузка и лист «Дневник» из «План тренировок.xlsx» (его первая строка — пример, она пропускается). Упражнения сопоставляются с программой по полному или короткому названию без учёта регистра; что не нашлось, попадает в дневник и награды, но не в подстройку. Повторная загрузка того же файла дублей не создаёт.

### Перенос из прежней версии

Старая версия хранила всё в `localStorage` (`training-journal:v1`, `training-settings:v1`, `training-drafts:v1`). Если новое приложение открыто на том же адресе, после входа на «Сегодня» появится карточка «Нашли старые тренировки»: переносятся записи («как пошло» → сложность), дата старта, замены, рабочие веса и сегодняшние черновики. Старые ключи не удаляются. На другом адресе этих данных не видно — тогда выгрузить Excel в старой версии и загрузить его здесь.

## Проверки

| Проект | Команды |

| backend | `npm test`, `npm run test:e2e` (нужен Postgres), `npm run lint`, `npm run lint:deps`, `npm run build` |
